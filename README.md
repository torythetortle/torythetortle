
# Hi, I'm Tory Lysik 👋

Data and graphics journalist, web developer, and five-language work-in-progress. Based in New York City. Oh, and I probably have CSPAN on in the background like its a podcast. 


I build tools and tell stories at the intersection of data, design, and public accountability — using code to uncover things that matter. I'm currently a Reporter at the **Tow Center for Digital Journalism at Columbia University**. 

My work has appeared at **Axios**, **The Marshall Project**, **Vox**, **the Associated Press**, **Columbia Journalism Review**, and others. It's also  been cited in congressional testimony and federal legislation.

---

## 🛠️ What I work with

**Languages & analysis:** Python · R · SQL · JavaScript  
**Graphics & interactivity:** D3 · Svelte · React · Mapbox · QGIS · ArcGIS · Datawrapper  
**Design:** Adobe Illustrator · Photoshop · Procreate · ai2html  
**Methods:** FOIA · Web scraping · OSINT · NLP · Computer vision · ETL pipelines
I am also a huge fan of figuring out how to ethically integrate AI into my stories and use it for good.
